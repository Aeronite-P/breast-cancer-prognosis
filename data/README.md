# Data

**Nothing in this folder is committed to Git** (except this file). Everything here is either
re-downloadable from public sources or regenerated by the scripts; the exact files used are recorded
with checksums in [`../reproducibility/cohort_manifest.csv`](../reproducibility/cohort_manifest.csv).

## What each folder is

| Folder | What's in it | Made by | Size (Oct 2026) |
|---|---|---|---|
| `raw/` | METABRIC + TCGA clinical and expression downloads (incl. full transcriptome tarballs) | `src/fetch_data.py`, `src/boost_genes.py` | ~450 MB |
| `processed/` | merged modelling tables (`metabric_merged.csv`, `tcga_merged.csv`) | `src/fetch_data.py`, `src/validate_external.py` | ~2 MB |
| `stage_c_tiles/` | Phikon tile features, **original 244 patients** (≤ 200 × 768 per patient, float16) | `src/stage_c_pathology.py` | ~72 MB |
| `stage_c_tiles_full/` | Phikon tile features, **789 full-cohort patients** | `src/stage_c_pathology.py --all` | ~234 MB |
| `stage_c_coords/` | level-0 position of every saved tile (789 full-cohort patients) | `src/stage_c_pathology.py --all` | ~3 MB |
| `stage_k_heatmaps/` | thumbnails, top tiles and attention for the 4 heatmap examples | `src/stage_k_heatmaps.py` | ~8 MB |
| `stage_n_tissue/` | per-tile cluster labels and attention; verified example crops (B4, C1) | `src/stage_n_tissue.py`, `src/stage_o_followups.py` | ~19 MB |
| `stage_c_features/`, `stage_c_matched/` | early (July) ResNet-feature runs, kept for the record | `src/stage_c_local.py`, `src/stage_c_parallel.py` | ~3 MB |
| `logs/` | logs of every long run (download runs 1–3, analyses) | the scripts, when run in the background | < 1 MB |

Whole slides are **never kept**: each one is downloaded from GDC, checked against its MD5, cut into tiles,
summarised by Phikon, and deleted (~800 GB downloaded in total; ~300 MB of features kept).

## How to (re)generate
```bash
source .venv/bin/activate
python src/fetch_data.py                 # public clinical + gene data (cBioPortal)
python src/stage_c_pathology.py --all    # every TCGA-BRCA diagnostic slide -> Phikon features (resumable)
```

## Where the data comes from (provenance)
All data is public: clinical and gene data through the [cBioPortal](https://www.cbioportal.org) REST API,
diagnostic slides through the [GDC](https://portal.gdc.cancer.gov) API. No private, patient-identifiable,
or restricted data is used.

| Cohort | Study ID | Source publications |
|---|---|---|
| METABRIC | `brca_metabric` | Curtis et al., *Nature* 2012; Pereira et al., *Nat Commun* 2016 |
| TCGA-BRCA (PanCancer Atlas) | `brca_tcga_pan_can_atlas_2018` | TCGA Network, *Nature* 2012; Hoadley et al., *Cell* 2018 |

**Please also cite cBioPortal if you publish:** Cerami et al., *Cancer Discovery* 2012; Gao et al., *Science Signaling* 2013.
